# Security policy

## Scope

Extension Template is a local VS Code extension. Replace this section with what
your extension actually touches: which files it reads or writes, whether it runs
any commands or scripts, and whether it talks to the network.

The template itself does not send data anywhere and collects no telemetry.

## Reporting a vulnerability

Report a vulnerability privately through the repository's **Security** tab
("Report a vulnerability"). Please include:

- a description of the issue,
- steps to reproduce,
- the affected version.

We aim to acknowledge reports within a few days.
